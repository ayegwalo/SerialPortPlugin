
# SerialPortPlugin

A C++ serial port plugin demonstrating a modular plugin architecture and simulated serial communication using a local loopback buffer.

## Overview

SerialPortPlugin is a C++ project designed to demonstrate how a serial port interface can be implemented through an abstract plugin architecture.

The project simulates serial communication without requiring a physical serial device. Data written to the simulated port is stored in an internal buffer and can subsequently be read back.

## Features

- Abstract plugin architecture
- Serial port interface implementation
- Simulated serial port opening and closing
- Data transmission using a buffer
- Partial data reading
- Handling of empty buffers
- Error handling for read and write operations on closed ports

## Architecture

| Component | Responsibility |
|---|---|
| CAbstractPlugin | Defines the abstract plugin base |
| CSerialPortInterface | Defines the serial port interface |
| CSerialPort | Implements the simulated serial port |
| CMyString | Provides a custom string class |
| main.cpp | Runs the application and tests |

## How It Works

The project uses a local loopback simulation:

1. Open the simulated serial port.
2. Write data into the internal buffer.
3. Read data from the buffer.
4. Handle partial reads and empty buffers.
5. Close the serial port.

The implementation uses `std::deque<char>` as its internal data buffer and a Boolean state variable to track whether the port is open.

**Note:** This implementation simulates serial communication. It does not currently communicate with physical serial hardware.

## Testing

The implementation was manually tested against the following scenarios:

- Reading from a closed port.
- Writing to a closed port.
- Opening and closing the port.
- Writing data to the buffer.
- Reading partial and remaining data.
- Reading from an empty buffer.
- Attempting operations after closing the port.

## Build Requirements

- C++ compiler supporting the C++ standard specified in CMakeLists.txt

- Standard C++ library

## Build Instructions

From the project root directory:

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

Run the executable generated by CMake from the build directory.
